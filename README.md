# Hangar
> Your code agent workspace. Park, launch, and monitor oh-my-pi sessions from one place.

## Quick Start
```bash
git clone https://github.com/SEU_USER/hangar
cd hangar
npm run setup
npm run dev
```
Open http://localhost:5173

## Features
- Kanban view — Idle / Running / Paused / Done
- Live session chat via WebSocket
- PWA — installs on mobile
- oh-my-pi native support
